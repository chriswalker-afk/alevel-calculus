    Rules, hints and the important maths

    A product is zero only when at least one factor is zero. For example, (x + 5)(x − 2) = 0 gives x = −5 or x = 2. The numbers in the brackets are not usually the roots.

    Start each lock with 3 stars. A wrong mathematical answer or a clue reduces the available stars by one, to a minimum of 1. Invalid or incomplete entries are not penalised. Studying the full solution opens the lock for 0 stars.

    Either root order is accepted. For a repeated root, enter the single distinct solution and leave the other box blank, or enter it twice. Zero is a valid bracket number and a valid root. In the final area, first collect the equation into x² + bx + c = 0.
