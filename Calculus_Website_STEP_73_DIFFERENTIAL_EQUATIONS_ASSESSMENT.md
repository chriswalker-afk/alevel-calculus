# Step 73 - First-Order Differential Equations - AO1-AO3 and modelling limits

**Status:** Complete

Step 73 extends the Step 72 first-order differential-equations topic to the full five-mode journey without creating a new topic or a parallel solving engine.

## Added learning coverage

- Memorise: rate-language/sign translation; separation/integration order; general-to-particular solution; model interpretation checks.
- AO1: construct proportionality equations; solve separable equations and apply conditions; interpret signs, units and long-term behaviour.
- AO2: diagnose invalid separation/condition use; judge modelling assumptions and limitations.
- AO3: construct, solve, interpret and critique an unfamiliar first-order model.

The durable modelling sequence is:

**translate -> separate -> integrate -> general solution -> condition -> particular solution -> interpret sign/units/long-term behaviour -> state assumptions/realistic domain/limitations**

## Reuse contract

- Step 72 `FamilyOfCurvesExplorer` and Understand activities remain intact.
- Post-separation integration reuses `integration-method-vocabulary.js`; no DE-specific integration method taxonomy is introduced.
- Memory Lab, QuestionShell, GeneratorRunner, DiagnosticRouter and Help routing remain shared/canonical.
- Diagnostic routing identifies the first broken stage: translation, separation, integration, condition application, or model interpretation/validity.

## Modelling rule

An exact mathematical solution is not evidence that the model is realistic for all values of the independent variable. Students must distinguish mathematical behaviour from assumptions and limitations, attach correct units/signs, and avoid blind extrapolation beyond a realistic domain.
